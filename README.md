# Cape Town Sun Path

A single-page, no-install web tool for early-stage architectural site analysis: type any Cape Town address, it is geocoded with OpenStreetMap's Nominatim (no API key) and pinned on a map, then the browser computes the sun's position with the NOAA solar equations to draw a stereographic sun-path diagram for the summer solstice (21 Dec), the equinox, the winter solstice (21 Jun) and any date you choose, with hourly markers in SAST. It also ranks the eight facade orientations (N, NE, E, SE, S, SW, W, NW) by hours of direct sun and cosine-weighted relative solar exposure for summer and winter, a reminder that in the southern hemisphere north-facing walls catch the low winter sun while the high summer sun mostly hits east and west. Results assume clear sky and no shading from neighbours or terrain. It is plain HTML/JS in `index.html`; open it in any browser or host it as a static file.
